# Technical Notes

This document describes the technical findings behind the
Brother MFC-9970CDW Community-Project Driver.

The implementation was developed through behavioral reverse engineering,
protocol observation, comparison of generated print streams, and testing
against the printer itself.

No proprietary Brother driver binaries are distributed with this project.

---

## Printing architecture

The MFC-9970CDW contains a PostScript interpreter and accepts print jobs
directly over TCP port 9100.

The Community-Project Driver therefore does not need the original Brother
rendering engine for normal printing.

The current printing path is:

    macOS application
          |
          v
    macOS CUPS / PostScript
          |
          v
    nativefilter
          |
          v
    PJL header + PostScript document
          |
          v
    TCP port 9100
          |
          v
    Brother MFC-9970CDW

The `nativefilter` is intentionally small. It does not rasterize the page.
It only adds the printer-specific PJL configuration before passing the
PostScript stream to the printer.

---

## Printer discovery

The printer advertises a raw printing service using Bonjour / DNS-SD:

    _pdl-datastream._tcp

A typical service discovered by macOS looks like:

    Brother MFC-9970CDW._pdl-datastream._tcp.local.

The actual Bonjour host name is device-specific and may look similar to:

    BRN001122334455.local

The installer discovers the printer dynamically. No fixed IP address or
device-specific BRN hostname is included in the public package.

This allows the printer to continue working after DHCP address changes.

## PJL configuration

Inspection of print jobs generated by the legacy Brother Linux driver
revealed several PJL settings required for the printer's different modes.

### Color

    @PJL SET RENDERMODE=COLOR

### Grayscale

    @PJL SET RENDERMODE=GRAYSCALE

### Normal 600 dpi mode

    @PJL SET RESOLUTION=600
    @PJL SET APTMODE=OFF

### Fine mode

Brother's Fine / 2400-dpi-class mode was observed to use:

    @PJL SET RESOLUTION=600
    @PJL SET APTMODE=ON4

The physical printer resolution remains 600 dpi. `APTMODE=ON4` enables
Brother's higher-quality Fine processing mode.

The Community-Project Driver therefore exposes:

- 600 dpi
- Fine / 2400-dpi-class

The second setting should not be interpreted as a literal native
2400 x 2400 dpi printer resolution.

---

## PostScript

The printer accepts standard PostScript directly.

The filter enters the PostScript language using PJL:

    @PJL ENTER LANGUAGE=POSTSCRIPT

The PostScript document is then passed through unchanged.

---

## Duplex printing

Duplex behavior is controlled using standard PostScript `setpagedevice`
commands.

### Duplex disabled

    << /Duplex false >> setpagedevice

### Long-edge duplex

    << /Duplex true /Tumble false >> setpagedevice

### Short-edge duplex

    << /Duplex true /Tumble true >> setpagedevice

Both long-edge and short-edge duplex modes were verified on the physical
MFC-9970CDW.

---

## Supply reporting

macOS can request printer supplies using the CUPS command mechanism:

    ReportLevels

The legacy Brother macOS driver used this mechanism instead of relying on
the generic CUPS SNMP supply implementation.

The Community-Project Driver implements its own command filter:

    commandlevels-direct

When macOS requests `ReportLevels`, the filter queries the printer directly
via SNMP and returns CUPS marker attributes.

---

## Brother private SNMP data

Useful supply percentages are available through the Brother private OID:

    1.3.6.1.4.1.2435.2.3.9.4.2.1.5.5.8.0

The returned data contains identifiers and integer percentage values.

Observed identifiers:

| ID | Component |
|---|---|
| `0x6F` | Black toner |
| `0x70` | Cyan toner |
| `0x71` | Magenta toner |
| `0x72` | Yellow toner |
| `0x41` | Drum |
| `0x69` | Belt |
| `0x6A` | Fuser |
| `0x6B` | Laser |
| `0x6C` | Paper feed MP |
| `0x6D` | Paper feed 1 |

The percentage values were verified by comparing the decoded SNMP data
against the maintenance information shown by the printer's own web
interface.

The current macOS driver exposes:

- Cyan toner
- Magenta toner
- Yellow toner
- Black toner
- Drum
- Belt
- Fuser

The additional maintenance counters are currently decoded but are not
exposed in the macOS supply UI.

---

## CUPS marker attributes

The `ReportLevels` command filter returns attributes such as:

    ATTR: marker-names=Cyan,Magenta,Yellow,Black,Drum,Belt,Fuser
    ATTR: marker-types=toner,toner,toner,toner,opc,transfer-unit,fuser
    ATTR: marker-levels=...

These attributes allow macOS to display the supply information in
Printer Settings.

## Development history

The direct driver was not the first implementation.

Development initially used a Linux CUPS print server running Brother's
legacy Linux driver.

That environment provided a useful reference for understanding:

- Brother print-job generation
- quality settings
- grayscale and color modes
- duplex behavior
- printer-specific PJL
- CUPS filtering behavior

The original Brother macOS driver was also examined to understand how
supply reporting was integrated into macOS.

Once direct PostScript printing, duplex control and supply reporting had
been reproduced independently, the Linux print server and legacy Brother
binaries were removed from the final printing path.

---

## Legacy Brother software

The legacy Brother Linux and macOS drivers were used only as behavioral
references during development.

The Community-Project Driver does not redistribute:

- Brother macOS driver binaries
- Brother Linux driver binaries
- Brother command filters
- Brother raster filters

The final implementation consists of independent shell filters, a modified
CUPS-derived PPD and installer scripts.

---

## PPD origin

The project's PPD is derived from the CUPS generic PostScript printer PPD.

The original copyright and Apache License 2.0 attribution are preserved
inside the file.

The PPD was modified for:

- MFC-9970CDW identification
- A4 defaults
- color/grayscale selection
- quality selection
- duplex support
- CUPS command handling
- supply reporting
- Community-Project filters

---

## macOS Driver Version 10.4

macOS may display:

    Driver Version: 10.4

This is not the Community-Project Driver version.

It refers to Apple's generic PostScript printing infrastructure used for
PPD-based printers.

The project version is stored in the PPD and is shown separately as the
PPD file version.

---

## Current limitations

The driver currently relies on the traditional PPD-based CUPS driver model.

That driver model is deprecated in modern CUPS and may eventually disappear
from future versions of macOS.

A future implementation may therefore need to move toward a driverless
printing architecture or a Printer Application.

Automatic installation currently expects exactly one discoverable
MFC-9970CDW on the local network.

The installer intentionally aborts if multiple matching printers are found
rather than selecting one arbitrarily.

## Tested functionality

The following functionality has been tested on physical hardware:

- automatic Bonjour discovery
- direct TCP port 9100 printing
- color printing
- grayscale printing
- 600 dpi mode
- Fine mode
- long-edge duplex
- short-edge duplex
- toner level reporting
- drum level reporting
- belt level reporting
- fuser level reporting
- installation using a macOS `.pkg`

Testing has also been performed on more than one Mac to verify that the
driver does not depend on development-machine state or legacy Brother
software.
