About this driver

Brother MFC-9970CDW Community-Project Driver v__VERSION__ is an independent implementation for modern macOS.

Supported features

The current driver supports color and grayscale printing, 600 dpi, Brother Fine / 2400-dpi-class mode, long-edge duplex, short-edge duplex, automatic Bonjour discovery and direct supply-level reporting.

Supply information includes Cyan, Magenta, Yellow and Black toner, as well as Drum, Belt and Fuser status.

How it works

Printing is sent directly from macOS to the MFC-9970CDW using the printer's PostScript interpreter over TCP port 9100.

Supply levels are queried directly from the printer using SNMP.

No Brother proprietary driver binaries are included with this package.

Automatic discovery

During installation the driver searches the local network for a Brother MFC-9970CDW advertised through Bonjour / DNS-SD.

If exactly one compatible printer is found, the printer queue is configured automatically. The printer does not need a fixed IP address.

If multiple MFC-9970CDW printers are discovered, installation currently stops rather than choosing a printer arbitrarily.

macOS “Driver Version 10.4”

macOS may display Driver Version 10.4 in Printer Information. This refers to Apple's generic PostScript printing infrastructure and is not the version of this project.

The Community-Project Driver version is __VERSION__.

Compatibility note

This driver currently uses the traditional PPD-based macOS/CUPS printer driver interface. That interface is deprecated and may eventually be removed from future versions of macOS or CUPS.

Testing and feedback

This is a public beta. Testing on different Macs, macOS versions, printer firmware versions and network configurations is very welcome.

Please report successful tests as well as problems through the project's issue tracker. Useful reports include the macOS version, Apple Silicon or Intel architecture, printer connection type, application used for printing, and the feature being tested.

Please avoid publishing private IP addresses, serial numbers, MAC addresses or other device-specific identifiers unless they are actually needed to diagnose a problem.
