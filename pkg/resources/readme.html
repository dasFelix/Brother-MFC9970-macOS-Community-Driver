About this driver

Brother MFC-9970CDW macOS Community Driver v__VERSION__ is an independent community implementation for modern macOS.

Features

  • Automatic Bonjour printer discovery
  • Direct PostScript printing over TCP port 9100
  • Color and grayscale printing
  • 600 dpi mode
  • Brother Fine / 2400-dpi-class mode
  • Long-edge and short-edge duplex
  • Cyan, Magenta, Yellow and Black toner levels
  • Drum, Belt and Fuser levels
  • Automatic printer queue creation

No legacy Brother driver required

The package does not include or require Brother's old proprietary macOS driver binaries.

The printing path does not require Rosetta and does not require an external Linux/CUPS print server.

Automatic discovery

The installer searches the local network for a Brother MFC-9970CDW advertised through Bonjour / DNS-SD.

If exactly one compatible printer is found, it is configured automatically. A fixed printer IP address is not required.

Supply information

Supply information is queried directly from the printer using SNMP and reported to macOS through the CUPS ReportLevels mechanism.

macOS Driver Version 10.4

macOS may separately display Driver Version 10.4. That number belongs to Apple's generic PostScript printing infrastructure and is not the version of this project.

The Community Driver version installed by this package is __VERSION__.

Compatibility

macOS 27.x is the currently tested platform. macOS 26.x is expected to work, and community testing is welcome.

The current implementation uses the traditional PPD-based CUPS printer driver architecture. This architecture is deprecated, so compatibility with future macOS releases cannot be guaranteed.

Testing and feedback

This is a public beta. Testing reports, bug reports and successful test results are all welcome through the project's GitHub issue tracker.
