Brother MFC-9970CDW Community-Project Driver

Version __VERSION__ – Public Beta

This installer adds an unofficial community driver for the Brother MFC-9970CDW to modern macOS systems.

The driver was created to keep this printer usable without requiring Brother's legacy x86 macOS printer driver, Rosetta in the printing path, or an external Linux print server.

Before continuing

Please make sure the Brother MFC-9970CDW is switched on and connected to the same local network as this Mac.

The installer will automatically search for the printer using Bonjour and configure it. No printer IP address needs to be entered manually.

This is an unofficial community project and is not affiliated with, endorsed by, or supported by Brother Industries, Ltd.
