Brother MFC-9970CDW macOS Community Driver

Version __VERSION__ – Public Beta

This installer adds an unofficial community driver for the Brother MFC-9970CDW to modern macOS systems.

The driver keeps the printer usable without Brother's legacy x86 macOS printer driver, Rosetta in the printing path, or an external Linux print server.

Before continuing

Printer connection
Make sure the Brother MFC-9970CDW is powered on and connected to the same local network as this Mac.
Automatic setup
The installer will automatically discover the printer using Bonjour and configure the printer queue. No printer IP address needs to be entered manually.
